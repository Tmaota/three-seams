任务：写一个 Node 脚本 `scripts/gen-maps.mjs`，程序化生成四张西幻像素风交互地图，并把产物写成 4 个 React 组件文件。写完脚本后执行它，自检产物，除以下列出文件外不要改任何其他文件。

【产物】
1. scripts/gen-maps.mjs —— 生成器本体（种子随机，用 mulberry32(seed) 保证可复现：world=20251019, circlet=77, corridors=777, outer=7777）
2. components/maps/art-world.tsx —— 世界总图，viewBox="0 0 256 176"
3. components/maps/art-circlet.tsx —— 低语者之环区域图，viewBox="0 0 200 140"
4. components/maps/art-corridors.tsx —— 灰色走廊区域图，viewBox="0 0 256 112"
5. components/maps/art-outer.tsx —— 外围场景区域图，viewBox="0 0 256 144"
6. 同时把每张图也另存为独立 SVG 到 public/maps/{world,circlet,corridors,outer}.svg（内容与 tsx 完全一致）

每个 art-*.tsx 的结构：
```tsx
export default function ArtWorld() {
  return (<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 256 176" shape-rendering="crispEdges" role="img" aria-label="三缝之地世界地图">
    ...全部地图元素...
  </svg>)
}
export const hotspots: { id: string; label: string; x: number; y: number; w: number; h: number }[] = [
  // 生成器按自己实际画的位置填坐标
]
```

【通用硬性规格】
- 所有 rect 整数坐标；shape-rendering="crispEdges"；禁止渐变/圆角/半透明/旋转
- 文字标签用 <text>：font-family="Noto Serif SC, serif"，fill="#2b2233"，paint-order="stroke"，stroke="#f0e0c0" stroke-width="0.8"（描边光环保证在任意底色上可读），font-size 4.5（区域图 5），text-anchor="middle"
- 调色板（只准用）：深海 #2f4460｜浅海/湖水 #4a6a8c｜波光/雪/沙 #f0e0c0｜陆纹 #8c8578｜山灰 #5c564d｜林绿 #5a8c4a｜深林 #3d5c2e｜风暴紫 #6a4a8c｜暗紫 #3d2b57｜余烬 #c8502e｜深红 #8c2f1e｜金 #e8b64c｜暗金 #c98a2e｜墨 #2b2233
- 细节密度要求（这是重点，色块感=不合格）：
  · 海面：满铺深海+每 6~10px 一组 1px 浅色波纹（两小横点），近岸一圈浅海色+1px 沙线 #f0e0c0
  · 森林：单棵树精灵密铺（1px 墨色树干 + 2×2 树冠，树冠随机取 #5a8c4a/#3d5c2e 两色 60/40 混合，林间留 1px 空隙），缄林密度约 55%，石根森林绿冠换 #8c8578 石化树
  · 山脉：连绵山脊（3~5px 宽的山体 #5c564d + 1px 墨色右下阴影 + 偶尔 1px 雪顶 #f0e0c0），山与山相叠错落
  · 平原/高原底色：#f0e0c0 打底 + 稀疏 #8c8578 草地点缀（约 8% 密度）
  · 河流：1px #4a6a8c 蜿蜒折线（每 3~6px 折一次）
  · 道路：1px #c98a2e 虚线（画 2 空 1）
  · 城市：建筑群精灵（2×3 屋体 + 1px 墨色轮廓 + 1px 金色屋顶，三五个聚在一起），外墙 1px 墨色
  · 每张图四角留 2px 墨色边框线，右上角画 6×6 指北针（N 用一个 1×3 金箭头+墨杆）
